# Style: UI Behavior

Applies to `ui_behavior_<slug>.md` documents.

---

## Output Format

```md
## 8. UI Behavior

**UI1:** [Feature-specific UI behavior]
**UI2:** [Feature-specific UI behavior]
**UI3:** [Group Name]: follow General UI Behavior Rules.
**UI4:** [Group Name]: follow General UI Behavior Rules.
```

---

## Section Heading

- Always use `## 8. UI Behavior` as the top-level heading.

---

## Entry Formatting

- Each entry is one line: `**UIN:** [Description]`
- Number entries sequentially starting from UI1.
- Feature-specific entries come first.
- Shared UI behavior references come after all feature-specific entries.

---

## Shared Reference Format

- Format: `**UIN:** [Group Name]: follow General UI Behavior Rules.`
- Use the exact group name from the reference file.
- One reference per relevant group.

---

## Ordering

1. Feature-specific UI behavior entries
2. Shared UI behavior references (if any)
