# Style: Business Rules

Applies to `business_rule_<slug>.md` documents.

---

## Output Format

```md
## 4. Business Rules

**R1:** <one rule statement>

**R2:** <one rule statement>
```

---

## Numbering

- Number rules sequentially: R1, R2, R3…
- Use bold label format: `**R1:**`
- Preserve numbering from source if the source already has rule IDs.
